# Документация проекта

## Описание базового синтаксиса записи и форматирования

### Автотесты с Allure отчетностью

Проект содержит набор автоматизированных тестов для тестирования:
- Выполнения операции сложения в калькуляторе, с задержкой
- Полный цикл оформления заказа в интернет-магазине

Проект использует следующие технологии и синтаксис:

1. **Python** - Основной язык программирования для написания тестов.
2. **Selenium** - Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest** - Фреймворк для написания и запуска тестов.
4. **Allure** - Инструмент для генерации отчетов о выполнении тестов.
5. **ChromeDriver / FirefoxDriver** - драйверы браузеров

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Методы и функции тестов задокументированы.
- Все шаги теста размечаются с помощью `with allure.step` для улучшения читаемости отчетов.

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
    Или установка вручную:

   ```bash
   pip install pytest selenium allure-pytest
   ```

2. Установите драйвера браузеров, используя менеджер веб-драйверов:

   ```bash
   pip install webdriver-manager
   ```

3. Запуск всех тестов:

   ```bash
   pytest 
   ```

4. Запуск тестов с подробным выводом в консоль:

   ```bash
   pytest -v
   ```
   Эта команда запустит тесты и выведет подробный результат в консоли

## Ручной запуск тестов и формирование Allure отчета

1. Эта команда запускает тесты и формирует папку `results` с результатами

   ```bash
   pytest --alluredir=./results
   ```
2. Эта команда генерирует отчет на основе результатов тестов

   ```bash
   allure generate ./results -o ./final-report
   ```
   
3. Эта команда открывает сгенерированный отчет в браузере по умолчанию
   ```bash
   allure open ./final-report
   ```

### Быстрый запуск с помощью run.sh

* Для удобства работы с проектом создан скрипт в файле `run.sh`, 
который автоматизирует процесс запуска тестов и формирования Allure отчета.

* Что делает скрипт:
  - Очищает старые результаты - удаляет папку с предыдущими результатами тестов
  - Запускает тесты - выполняет pytest с сохранением Allure результатов в папку ./results
  - Сохраняет историю - переносит историю предыдущих отчетов для построения графиков трендов
  - Генерирует отчет - создает HTML отчет Allure в папке ./final-report
  - Открывает отчет - автоматически открывает сгенерированный отчет в браузере

1. Как использовать run.sh:
 - Выполнить команду в терминале:
   ```bash
   ./run.sh
   ```

## Результаты отчета в Allure:

#### Тест №1
   - **Название теста**: `Работа калькулятора с задержкой`.
   - **Описание теста**: Описание, что тест проверяет операцию сложения в калькуляторе.
   - с установленной задержкой 45 секунд.
   - **Серьезность теста**: Critical
   - **Шаги теста**:
     - Открыть страницу калькулятора.
     - Установить задержку.
     - Выполнить операцию сложения.
     - Получить результат вычисления.
     - Проверить результат.
   - **Результат**: Выполнение теста с указанием ожидаемого и фактического результата.

#### Тест №2
   - **Название теста**: `Полный сценарий оформления заказа`.
   - **Описание теста**: Описание, что тест проверяет полный цикл работы с интернет-магазином.
   - **Серьезность теста**: Blocker
   - **Шаги теста**:
     - Авторизация пользователя в интернет-магазине.
     - Добавление товаров в корзину.
     - Проверка содержимого корзины.
     - Оформление заказа.
     - Проверить результат.
   - **Результат**: Выполнение теста с указанием ожидаемого и фактического результата.
